# DevOps Student Engineering Portal

## Project Description
The DevOps Student Engineering Portal is a foundational web application created as part of an academic Git collaboration exercise. It establishes a baseline student information profile for a DevOps-focused Master of Computer Applications (MCA) student, serving as the common code foundation for multi-developer team collaboration.

## Application Scope
- Base static structure displaying student profile attributes: Student Name, Register Number, Programme.
- Initial clean and accessible styling foundation.
- Baseline button placeholder for future dynamic interactivity.
- Lightweight, framework-free implementation with clear traceability across `index.html`, `style.css`, and `script.js`.

## Basic Git Workflow
1. Student 1 initializes the repository and establishes the baseline on branch `main`.
2. Student 2 branches from `main` to implement UI enhancements.
3. Student 3 branches from `main` to implement client-side interactive logic.
4. Changes are contributed via pull requests and reviewed collaboratively.
